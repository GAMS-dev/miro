R packages
==========

The R version and R packages shipped with each GAMS MIRO release, starting with
GAMS MIRO 2.14. This list is generated automatically for each release. Packages with a
development version (e.g. ``1.14.0.9999``) are built from versions maintained by GAMS,
see `GAMS on GitHub <https://github.com/GAMS-dev>`__.
